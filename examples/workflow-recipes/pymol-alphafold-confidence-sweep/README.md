# AlphaFold Confidence Sweep

Open a local AlphaFold model in PyMOL, color it by confidence, isolate uncertain regions, and export a polished confidence-focused still.

- App: `pymol`
- Difficulty: `operator`
- Estimated time: `7 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **AlphaFold model Q9H255**: ./examples/data/local/af-q9h255.pdb

## What Success Looks Like
- The AlphaFold model is visible in PyMOL with confidence coloring.
- Low-confidence regions are isolated and emphasized in a close-up view.
- Overview and detail scenes are stored, and a final export is written.
