# Cryo-EM Map Fit Review Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open the local cryo-EM model and map.**: Load the fitted hemoglobin model and its cryo-EM map, then switch the map to a clean mesh view.
- **Fit the model into the map and inspect the fit.**: Run fitmap, move through mesh and orthoplane views, and store the fitted presentation framing.
- **Apply a presentation preset and export.**: Enable a publication-friendly preset and save the final map-fit image.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
