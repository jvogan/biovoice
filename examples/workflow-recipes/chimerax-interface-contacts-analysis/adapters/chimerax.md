# Interface or Contacts Analysis Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open hemoglobin and isolate chains A and B.**: Load the tetramer and narrow the view to the A/B interface.
- **Compute interface contacts and hydrogen bonds.**: Run contact and hydrogen bond analysis across the chain interface.
- **Apply the clean preset and export the interface.**: Use a silhouette presentation preset and save the interface shot.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
