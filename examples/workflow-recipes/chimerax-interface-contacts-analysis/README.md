# Interface or Contacts Analysis

Open a multichain complex, isolate an interface, compute contacts and hydrogen bonds, and export the interface view.

- App: `chimerax`
- Difficulty: `operator`
- Estimated time: `7 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **Human hemoglobin tetramer**: ./examples/data/local/4hhb.pdb

## What Success Looks Like
- 4HHB is loaded and the A/B interface is isolated.
- Contacts or hydrogen bonds are visible.
- Interface surface and export are complete.
