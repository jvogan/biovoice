# Crystal Packing Contacts

Expand crystallographic symmetry around a ligand-bound structure, isolate the packing shell near the inhibitor, and export a polished packing-contact still.

- App: `pymol`
- Difficulty: `deep-dive`
- Estimated time: `8 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **HIV protease with inhibitor**: ./examples/data/local/1hsg.pdb

## What Success Looks Like
- 1HSG is loaded and the inhibitor is visible.
- Symmetry mates are generated around the ligand.
- Only the local packing shell is emphasized near the inhibitor.
- A polished packing-contact PNG export is written.
