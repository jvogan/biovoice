# Biological Assembly Tour Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open the model and expand the biological assembly.**: Load the local 8WJ1 cryo-EM model, color it by chain, expand the assembly, and store the overview.
- **Tile briefly and settle into the hero framing.**: Use tile mode to inspect the assembly layout, then collapse back to a single presentation camera and store the hero view.
- **Recall the hero framing and export the still.**: Recall the polished hero view, strengthen the presentation preset, and export the final assembly still.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
