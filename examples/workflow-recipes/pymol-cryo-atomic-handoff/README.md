# Cryo-Atomic Handoff

Load a local cryo-EM hemoglobin model and map in PyMOL, show the fitted atomic model against the density, focus a heme neighborhood, and export a polished cutaway still.

- App: `pymol`
- Difficulty: `deep-dive`
- Estimated time: `9 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **Human oxy hemoglobin cryo-EM model**: ./examples/data/local/8wj1.cif
- **Human oxy hemoglobin cryo-EM map**: ./examples/data/local/emd_37575.map

## What Success Looks Like
- The local model and cryo-EM map are loaded into PyMOL.
- The atomic model and a contoured density view are visible together.
- A heme-centered cutaway scene is stored and exported cleanly.
