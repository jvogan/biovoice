# GroEL Cavity Tour Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open GroEL and establish the overview.**: Load the local assembly, color by chain, apply the large-assembly preset, and save a global overview view.
- **Color the domain architecture and reveal the cavity.**: Color the GroEL apical, intermediate, and equatorial domains, clip into the cavity, and save the hero view.
- **Inspect the layout and export the cavity hero shot.**: Briefly tile the view, return to the cavity hero framing, and export the final still.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
