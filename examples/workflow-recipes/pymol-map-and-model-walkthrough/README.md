# Map and Model Walkthrough

Generate a synthetic density map around a structure, contour it as mesh or surface, and walk between full-model and pocket views.

- App: `pymol`
- Difficulty: `operator`
- Estimated time: `7 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **Ubiquitin**: ./examples/data/local/1ubq.pdb

## What Success Looks Like
- 1UBQ is loaded.
- A gaussian map has been generated.
- A mesh or surface contour is visible near the selected region.
- Scene transitions between overview and focus views are stored.
