# Selection and Storyboarding

Create named selections for chains, residue spans, and ligand neighborhoods, then step through them as a storyboard.

- App: `pymol`
- Difficulty: `deep-dive`
- Estimated time: `9 minutes`
- Voice mode: `push_to_talk`
- Last verified: `2026-04-04`

## Sample Data
- **HIV protease with inhibitor**: ./examples/data/local/1hsg.pdb

## What Success Looks Like
- Named selections exist for chains, catalytic residues, and ligand shell.
- Each storyboard stop is visible and stored as a scene.
- The final storyboard close-up can be recalled and exported cleanly.
