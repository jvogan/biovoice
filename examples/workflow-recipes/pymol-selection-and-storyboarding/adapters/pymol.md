# Selection and Storyboarding Adapter Notes

This recipe targets **pymol**.

## Structured Steps
- **Create reusable named selections.**: Build named selections for chain A, chain B, catalytic residues, and the ligand shell.
- **Step through the selections and store scenes.**: Orient and zoom to each named selection, then store a matching scene for the storyboard.
- **Export the final storyboard close-up.**: Recall the close-up scene and export a final still for reuse.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
