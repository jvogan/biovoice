# Ligand Interaction Explainer Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open the structure and style the protein and ligand.**: Load 1HSG, apply chain coloring, and switch the ligand to a more legible representation.
- **Build the pocket surface and compute interactions.**: Create a transparent pocket surface and overlay hydrogen bonds and clashes around the ligand.
- **Finish the pocket shot and export it.**: Set the camera, apply a presentation preset, and save a PNG.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
