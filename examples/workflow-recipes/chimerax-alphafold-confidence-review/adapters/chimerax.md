# AlphaFold Confidence Review Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open the AlphaFold model and color it by confidence.**: Load the local AlphaFold model and apply B-factor confidence coloring.
- **Find and focus the flexible region.**: Select a low-confidence loop, frame it, and compare cartoon and surface.
- **Apply a clean preset and export the result.**: Use a soft-light preset and save the final confidence review figure.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
