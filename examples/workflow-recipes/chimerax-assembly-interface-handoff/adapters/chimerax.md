# Assembly-To-Interface Handoff Adapter Notes

This recipe targets **chimerax**.

## Structured Steps
- **Open the assembly and save the overview camera.**: Load 8WJ1, expand the biological assembly, and save a clean overview view before focusing on the interface.
- **Focus the A/B interface and compute its contact network.**: Return to one focused interface, compute contacts and hydrogen bonds across chains A and B, and save the interface hero view.
- **Recall the interface hero view and export it cleanly.**: Return to the saved interface view, apply the polished comparison preset, and export the final interface still.

## Notes
- The voice console compiles these recipe steps into structured tool calls.
- The manual command list in `recipe.md` is the direct fallback if you want to run the workflow without voice.
